# ☑️ Checky Check

Welcome to the **Checky Check**! This is a simple, playful, and interactive web application that lets you generate custom grid layouts similar to the GitHub contribution calendar. 

Designed with a bouncy, glossy, and "childish" aesthetic, it's perfect for tracking habits, creating pixel art, or just having fun popping bubbles!

## ✨ Features

*   **Dynamic Grid Generation:** Input any number of rows and columns to instantly generate a custom grid.
*   **Interactive Cells:**
    *   **Single-click:** Toggle a cell on (bouncy and colorful) or off (gray).
    *   **Double-click:** Toggle a cell into an "inactive" state (greyed out and pushed down). You cannot color an inactive cell until you double-click it again to wake it up!
*   **Playful Themes:** Choose from 10 fun, glossy color variants (like Bubblegum, Slime Green, and Cotton Candy) to style your active grid cells.
*   **Responsive UI:** The grid dynamically scales, and the UI uses glassmorphism and glossy effects for a smooth, modern, and fun user experience.
*   **Single-File Setup:** Everything (HTML, CSS, and JS) is contained within a single `index.html` file for ultimate simplicity.

## 🚀 How to Use

1.  **Open the App:** Simply open the `index.html` file in any modern web browser. No server or installation is required!
2.  **Set the Size:** Enter your desired number of `Rows` and `Columns` in the input fields at the top.
3.  **Generate:** Click the **"Make Grid! ✨"** button to build your grid. Watch it pop into existence!
4.  **Pick a Flavor:** Click on one of the circular color swatches below the inputs to change your theme color.
5.  **Interact:**
    *   Click a box to color it in.
    *   Click it again to clear it.
    *   Double-click a box to disable it.
    *   Double-click a disabled box to re-enable it.

## 🛠️ Technologies Used

*   **HTML5**
*   **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, animations, and heavy use of box-shadows/gradients for the "glossy" look.
*   **Vanilla JavaScript:** DOM manipulation and event delegation.
*   **Tailwind CSS:** Used via CDN for quick layout scaffolding and typography utility classes.
*   **Google Fonts:** Uses *Fredoka One* (for headings) and *Nunito* (for body text).
